🌸 Radhe Naam Jap Counter

A devotional Radhe Naam Jap Counter web app created as a learning project.

✨ Features

- 🙏 Unlimited Jap
- 🎯 Targeted Jap
- 📿 Mala counting
- 🏆 Achievement badges
- 🌸 Badge unlock celebrations
- 💾 Save Jap progress
- 📱 Installable PWA support
- 🎨 Radhe devotional background
- 🔊 Tap sound
- 🌺 Celebration animation

📱 Project

This project is being developed step by step while learning web development, Progressive Web Apps, and GitHub.

🚀 Status

The app is currently under development. More features such as Jap history, daily progress, streak tracking, and detailed progress will be added.
